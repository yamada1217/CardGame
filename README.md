# イジンデン オンライン

ダイソーのカードゲーム「イジンデン」のルールで遊べる、スマホ向けWebアプリです。

- 今できること: CPUとの対戦（1台で遊べる版）。ホーム画面に追加するとアプリのように全画面で動きます。
- 次に追加: 部屋のURLを送って友達と1対1のオンライン対戦（Firebase無料プラン）。
- お金はかかりません。公開は GitHub Pages、通信は Firebase の無料枠だけを使います。

## 動かし方

ビルド不要です。静的ファイルをそのまま配信します。

```sh
npx http-server -c-1 .   # http://localhost:8080 を開く
npm test                 # CPU同士を500戦させてエンジンを確認
```

## 構成

| ファイル | 中身 |
|---|---|
| `js/engine.js` | ルールの本体。「状態 + 行動 → 新しい状態」の純粋な関数 |
| `js/cards.js` | カードとデッキのデータ（今は仮データ） |
| `js/ai.js` | CPUの思考 |
| `js/app.js` | 画面とタップ操作 |
| `RULES.md` | 実装しているルールの仕様と、要確認の点 |
