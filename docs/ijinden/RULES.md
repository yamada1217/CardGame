# イジンデン ルール仕様（実装用） v0.2

ダイソー（大創出版）のトレーディングカードゲーム「イジンデン」をオンライン対戦アプリとして実装するための仕様です。
公式のルールカード・ルール補足・Q&A統合をもとに整理し、公式に記載がない点は **【未記載→実装方針】** として、アプリでの扱いを決めています。

- カードデータ: [`cards.json`](./cards.json)
- 出典一覧: 末尾の「出典」

## 0. 用語

| 用語 | 意味 |
|---|---|
| イジン | 戦場で攻撃（アタック）・ブロックするキャラクターカード。パワーを持つ |
| ハイケイ | 戦場に置かれ、効果が続くカード |
| マホウ | 使い切りのカード。魔力コストを持つ。使ったら墓地へ |
| マリョク | 魔力ゾーンに置いて、色とレベルを供給するカード |
| ガーディアン | 戦場に裏向きで置かれたカード。ブロッカーになれる |
| 起きている／寝ている | 縦向き（行動できる）／横向き（行動が制限される） |
| 遺業（いぎょう）能力 | カードが**戦場から墓地に置かれたとき**に発動できる能力（任意） |
| 特性 | 剣術・美術・音楽・思想・医術・志願 など。能力ではない（能力を失う効果では消えない） |

## 1. 場所（ゾーン）

各プレイヤーが以下の5つを持つ。

| 場所 | 公開 | 備考 |
|---|---|---|
| 山札 | 非公開 | 裏向き |
| 手札 | 持ち主のみ | 枚数は公開 |
| 魔力ゾーン | 表向きは公開、裏向きは持ち主のみ確認可 | |
| 戦場 | 表向きは公開、裏向き（ガーディアン）は**持ち主も見られない** | |
| 墓地 | 公開 | |

- 自分のカードを相手の場所に置くことはできない。カードの移動先は常に**持ち主の**場所（ルール補足）。
- 魔力ゾーンの裏向きカードの「種類」はシャッフル等で隠せない。相手は何が裏になったかを覚えておいてよい（Q&A）。→ 実装では、公開情報から裏になったカードは相手にも ID を知らせてよい（UI では「元○○」と表示可）。

## 2. デッキ構築

- 40枚以上。
- 同名カードは4枚まで。ただし「デッキに何枚でも入れてよい」カード（各色のストーン）は無制限。
- 同名カードでも別のカードとして扱う（Q&A）。
- 【実装方針】スターター3種（各40枚固定）に加えて、デッキ構築画面で自作デッキを作れる（40〜60枚、同名4枚まで、ストーンは無制限）。デッキに入れられるのは効果を実装済みのカード（`js/cards.js` の `CARDS`）だけで、ほかは一覧に「準備中」と表示する。上限60枚はアプリ独自の制限。スターターの構成は `cards.json` の `decks`（各スターター = イジン8種×2、ハイケイ2種×2、マホウ2種×2、ストーン×16）。

## 3. ゲームの準備

1. 各自デッキをシャッフルして山札にする。
2. 山札から6枚引いて手札にする。
3. 山札の上から4枚を**裏向きのまま**戦場に置く。これがガーディアン。
4. 先攻・後攻を決める（じゃんけん等）。→ 実装はランダム。
5. （オプション：手札の引き直し）先攻→後攻の順に、1回だけ手札6枚を山札に戻してシャッフルし、6枚引き直せる。ガーディアンはそのまま。→ **実装では標準で有効**にする。

## 4. 勝利条件

- 自分のバトルで、**ブロッカーが指定されていないアタッカー**の解決に到達したとき、攻撃側の勝利（ゲーム終了）。
- 相手のターンの**スタートフェイズ開始時**に相手の山札が0枚なら、相手の敗北。
- 【未記載→実装方針】両者が同時に勝利条件を満たすケースは公式に規定なし。実装上は発生しない（山札切れはターン開始時のみ判定、バトル勝利は攻撃側のみ）ので考慮不要。投了は即敗北。

## 5. ターンの流れ

### 5.1 スタートフェイズ
1. 山札が0枚なら敗北（ゲーム終了）。
2. マリョク配置権を1、イジン召喚権を1にする。
3. 自分の**戦場の**寝ているカードをすべて起こす（魔力ゾーンは対象外）。
4. 「スタートフェイズ終了時」の能力を処理。

### 5.2 ドローフェイズ
- 1枚引く。**先攻の最初のターンは引かない**。
- （オプション：後攻2ドロー）後攻の最初のターンのみ2枚。→ 実装では標準無効。

### 5.3 メインフェイズ
- 開始時に「メインフェイズが開始したとき」の能力を処理（自分・相手どちらのメインフェイズかはカードの記載に従う）。
- 以下を**好きな順番で、条件を満たす限り何度でも**行える。
  - **マリョク配置**（配置権を1消費）: 手札のマリョクを**表向き**で魔力ゾーンに置く、または手札の**任意のカードを裏向き**で魔力ゾーンに置く。どちらも配置権1。
  - **イジン召喚**（召喚権を1消費）: 色条件とレベル条件を満たすイジンを表向きで戦場に置く。
  - **ハイケイ使用**: 色条件とレベル条件を満たすハイケイを戦場に置く。枚数制限なし。
  - **マホウ使用**: 色条件・レベル条件・魔力コスト・（書かれていれば）発動条件を満たすマホウを公開し、効果を解決して墓地に置く。枚数制限なし。マホウは「使わない」を選べない（使ったら効果は必ず解決）。
  - **バトル**: 1ターンに1回（カード効果で追加可能。例: ファイナルアタック）。
- 先攻1ターン目のバトル禁止の規定は**ない**（ただし出したばかりのイジンは即応がないとアタッカーにできない）。

### 5.4 エンドフェイズ
1. 「エンドフェイズが開始したとき」の能力を処理。
2. 使わなかったマリョク配置権・イジン召喚権が消える。
3. 「このターンの間」の効果が終わる。
4. 相手のターンへ。

- 【未記載→実装方針】手札の上限枚数は記載なし → **上限なし**。

## 6. カードを使う条件

| 条件 | 内容 | 対象 |
|---|---|---|
| 色条件 | そのカードと同じ色の**表向きマリョク**が自分の魔力ゾーンに1つ以上ある。多色カードはいずれか1色でよい（【要確認】多色イジン・ハイケイは未収録範囲のみ） | イジン・ハイケイ・マホウ |
| レベル条件 | 魔力ゾーンの「表向きマリョクのレベル合計 ＋ 裏向きカードの枚数」が、カードのレベル以上 | イジン・ハイケイ・マホウ |
| 魔力コスト | コストと同じ枚数のカードを、自分の魔力ゾーンから墓地に置く。表向き・裏向きどちらのカードでも払える | マホウのみ |
| 発動条件 | 「〜を指定して発動できる」等の条件。対象がいなければ使えない | 書かれたマホウのみ |

- マリョクには使用条件がない（配置権のみ）。
- 色の種類: 赤・青・緑・黄・紫 の5色。無色のカードもある（無色は色ではない）。
- 裏向きカードは色を持たない（色条件には使えない）。【根拠】ルールカードは「同じ色のマリョク」、Q&Aは「裏のカードは色の数に数えない」。
- 魔力コストを裏向きカードで払えることは、マルティン・ルターのQ&A（「相手はマホウ使用時に裏のカードを墓地に置けない」＝通常は置ける）から判断。
- コスト減少・レベル増加の効果がある場合は、変更後の値で判定（Q&A）。
- 魔力コストで墓地に置いたカードの遺業は発動しない（戦場から墓地ではないため）。

## 7. バトル

バトルは「アタックステップ → ブロックステップ → バトル解決ステップ」。

### 7.1 アタックステップ
- 攻撃側は、自分の戦場の**起きているイジン**を1体以上選んでアタッカーにし、寝かせる。
- そのターンに戦場に置かれたイジンは選べない（「即応」を除く）。
- ガーディアンはアタッカーにできない（カード効果で「イジンとしても扱う」場合を除く）。
- 「アタッカーになったとき」の能力（「航海」を含む）を処理する。

### 7.2 ブロックステップ
- 防御側は、各アタッカーに対して、自分の戦場の**起きているイジン**または**起きているガーディアン**を0体以上ブロッカーとして指定する。1体のアタッカーに複数指定可。1体のブロッカーは1体のアタッカーにのみ指定可。
- 寝ているカードはブロッカーにできない（「ウォッチャー」を除く）。
- 「ブロッカーになれない」イジンは指定不可。
- 「○○にブロックされない」はブロッカー**1体ごと**に判定（合計値ではない）。
- ダブルプレッシャー: 2体以上でなければブロックできない（1体だけの指定は不可）。ガーディアンを含めてもよい。解決前にブロッカーが1体に減ったら、そのアタッカーは「ブロッカー未指定」になる。トリプルプレッシャーは3体。
- アタッカー・ブロッカーの指定後に条件を満たさなくなった場合、その指定は解除され、条件が戻っても復活しない（Q&A）。
- 【未記載→実装方針】ブロックしたカードは**寝ない**（寝かせる記述が無いため）。

### 7.3 バトル解決ステップ
防御側がアタッカーを**1体ずつ選び**、以下を繰り返す（全アタッカーを解決するまで）。

1. 選ばれたアタッカーにブロッカーがいなければ → **攻撃側の勝利**（ゲーム終了）。
2. ブロッカーがいれば、パワーを比べる。
   - **アタッカー**は、ブロッカーの**パワー合計**が自分のパワー**以上**なら負け。
   - **イジンのブロッカー**は、それぞれ自分のパワーがアタッカーのパワー**以下**なら負け（同値は両方負け）。
   - **ガーディアンのブロッカー**は、アタッカーのパワーが**0以下**のときだけ勝つ。それ以外は負け（ガーディアンのパワーは0扱い）。
3. 負けたカードは同時に「破壊されている」状態になる。「破壊されたとき」「墓地に置かれたとき」能力はバトル解決の終了を待たずに発動・処理する。
4. 待機中の能力がなくなったら、破壊されているカードをまとめて墓地へ。遺業能力（任意）を処理。
5. 次のアタッカーへ。この破壊は、まだ解決していないアタッカーの判定には影響しない。

- 全アタッカーの解決が終わったら、戦場に残ったアタッカー・ブロッカーはその役割を失う。
- 例: アタッカー5000 vs ブロッカー（イジン3000＋ガーディアン）→ 合計3000 < 5000 なのでアタッカーは勝ち。イジン3000は負け、ガーディアンも負け → 両方破壊。
- 例: アタッカー4000 vs イジン4000 → 相打ち（両方破壊）。
- 例: アタッカー3000 vs イジン2000＋イジン2000 → 合計4000 ≥ 3000 なのでアタッカーは負け。各ブロッカーは2000 ≤ 3000 なので負け → 3体とも破壊。
- 破壊されたガーディアンは補充されない（補充の規定なし。カード効果でのみ増える）。

### 7.4 ゲーム上の意味（実装メモ）
- ガーディアン4体は、「イジンがいなくても1回ずつ攻撃を止められる壁」。ブロックすると（ほぼ必ず）破壊される。
- したがって攻撃側は「相手がブロックできる数（起きているイジン＋起きているガーディアン）より多くアタッカーを出す」ことで勝ちを狙う。

## 8. 能力の処理

### 8.1 発動の種類
- 「〜発動する」/ 書かれた条件で必ず発動（強制）。
- 「〜発動できる」: 任意。発動しないことを選べる（ただしマホウの使用は取り消せない）。
- 「1ターンに1回」の能力: 見送った場合、そのターンに未発動なら後で発動できる。複数体あればそれぞれ1回。
- 解決できない部分があっても、できる範囲で処理する（例: 山札1枚で3ドロー → 1枚だけ引く）。枚数指定が**条件**の能力（例: 山札5枚以上なら）は、満たさなければ発動不可。
- 「〜たびに」「〜されたとき」は相手側の出来事でも発動する。同じ出来事が複数回なら回数分発動。

### 8.2 待機と処理順（ルール補足）
- 条件を満たした能力は「発動待ち」になる。発動前にそのカードが別の場所へ移動するか裏向きになると、発動しない。
- **ターンプレイヤーが先に**自分の待機能力をすべて処理し、その後で相手が処理する。
- 待機能力が複数あれば、持ち主が1つ選んで処理。その処理で新たに待機した能力があれば、そちらを先に処理（入れ子・後入れ先出し）。
- 「戦場に置かれたとき」能力は、召喚・ハイケイ使用以外で置かれた場合（遺業・効果など）も発動する。その場合、色・レベル条件は不要。
- 装備品と同時に戦場に置かれたイジンの「戦場に置かれたとき」は発動しない。

### 8.3 破壊
- 戦場のカードは「破壊されている／いない」の状態を持つ。破壊する＝破壊されている状態にする。
- 他に行う処理（カード使用中・能力解決中・待機能力）がなくなった時点で、破壊されているカードを**まとめて同時に**墓地へ置く。
- 「破壊されていない状態にする」効果を受けたカードは墓地へ行かない（遺業は発動しない）。

### 8.4 遺業能力
- カードが**戦場から墓地に**置かれたときに発動できる（任意）。手札・魔力ゾーン・山札から墓地に置かれた場合は発動しない。
- **裏向きのガーディアンも対象**。ガーディアンが破壊されて墓地に置かれたら、表にして、そのカードに遺業があれば発動できる。マホウやマリョクも、ガーディアンとして戦場にあった場合にのみ遺業が発動しうる。
- 遺業の種類（`cards.json` の `legacy`）:

| コード | 表記 | 効果 |
|---|---|---|
| `draw1` | 1ドローする | 1枚引く |
| `manaize` | 魔力化 | これを裏向きで魔力ゾーンに置く（配置権は使わない） |
| `restore` | 復元 | これを表向きで魔力ゾーンに置く（配置権は使わない）。主にマリョク |
| `meifu` | 冥府発動 | このマホウを色・レベル・魔力コストを無視して使う（発動条件は必要）。墓地へ置かれる代わりに使用され、使用後は墓地へ |
| `hangon` | 反魂 | 自分のガーディアン1体を山札の下に戻して、墓地のこのイジンを戦場に置く（召喚権不要） |
| `kodama` | 木霊 | 手札か墓地から、これよりレベルの低いイジン1体を戦場に置く（召喚権不要） |
| `returnToHand` | これを手札に戻す | 墓地から手札へ |
| `returnToDeckTopOrBottom` | これを山札の上か下に戻す | 山札の上か下を選んで置く |

- 【実装方針】バトル中の冥府発動（例: ガーディアンのマホウ）は、ブロッカー指定が終わった後なので、そのマホウで出したカードはブロッカーにならない（リバイバルのQ&A）。

## 9. キーワード・用語

| キーワード | 効果 |
|---|---|
| 即応 | 戦場に置かれたターンでもアタッカーに選べる。選んだ後に失ってもアタッカーのまま |
| ダブルプレッシャー | 2体以上でなければブロックできない（7.2参照） |
| トリプルプレッシャー | 3体以上でなければブロックできない |
| ウォッチャー | 寝ていてもブロッカーに選べる |
| アタック+N | アタッカーに選ばれてから、アタッカーでなくなるまでパワー+N |
| ブロック+N | ブロッカーに選ばれてから、ブロッカーでなくなるまでパワー+N |
| パワー+N | この能力を持っている間パワー+N。複数あれば累積 |
| 航海 | 「航海-アタッカーになったとき、…」という能力の名前。他のカードが「航海を持つイジン」「航海が発動したとき」として参照する |
| 執筆 | 「執筆-ハイケイが戦場に置かれたとき、…」という能力の名前。相手のハイケイにも反応。「執筆は発動しない」効果で止まる |
| Nドロー | 山札からN枚引く |
| 破壊する | 8.3参照 |
| 寝かせる／起こす | 起きている→寝ている／寝ている→起きている |
| 手札に戻す | 戦場・魔力ゾーン・墓地のカードを持ち主の手札へ。表向きのカードは相手に見せてから |
| 魔力化・復元・反魂・木霊・冥府発動 | 8.4参照（遺業以外の能力として書かれることもある） |
| イジン召喚権+1 / マリョク配置権+1 | そのターンの権利を1増やす。余りはエンドフェイズに消える |
| スタンド | 魔力ゾーンに裏向きのこのイジンを、ブロックステップでブロッカーに選べる（表にして戦場へ。同色マリョクが必要。召喚権不要）。「戦場に置かれたとき」も発動する |
| 装備 | 別のイジンに重ねて置き、「装備：」の能力を与える。装備されたカードは「装備：」以外の特性をすべて失う（種類も失う）。装備先が戦場を離れるか裏向きになったら、装備カードは元の場所へ戻る |
| モータル | ブロッカーとのパワー比較に勝ったアタッカーは、解決後もアタッカーのまま残る。防御側が通常どおり次のアタッカーを選び、未指定のアタッカーを選べば攻撃側の勝利 |
| 喪神 | アタッカー1体をアタッカーでない状態にする（指定していたブロッカーも外れる）。遺業としても登場 |
| クアドラプルプレッシャー | 4体以上でなければブロックできない |
| 決起 | 「決起-マリョク配置によってカードが自分の魔力ゾーンに置かれたとき、…」という能力の名前。条件の「マリョクが4つ以上」は表向きマリョクのみ数える |
| 徴募 | 「徴募-この能力は墓地でも発動する。自分のエンドフェイズが開始したとき、このターンにアタッカーが破壊されているなら…」という能力の名前 |
| 魔導（赤魔導・青魔導など） | マホウに付く追加効果の名前。「○のカードが自分の戦場か魔力ゾーンにあるなら『…』を発揮してもよい」 |
| 勝鬨 | 「勝鬨-この能力は、これがアタッカーなら、これがバトル解決で勝ったときに発動する」という能力の名前（強制） |
| 躍進 | 「躍進-この能力は、自分がこのターンに魔力ゾーンの能力によって山札からカードを引いているなら…効果を発揮する」という能力の名前 |
| 冥装 | イジン召喚でイジンが自分の戦場に置かれるとき、墓地のこのカードをそのイジンに装備させてよい。パイロオーラ等は「マホウ使用で墓地に置かれた場合」だけ冥装を得る |
| 消耗 | これが（魔力ゾーンで）表向きの間、自分のスタートフェイズに裏にする。【非公式資料】カード上の注釈文による |
| ドレイン | これがバトル解決で破壊した相手のカードは、遺業能力が発動しない（例: ガーディアンの冥府発動を封じる）。【要確認】公式の定義文は未確認。非公式の実装・攻略記事2件の記述が一致 |
| 「この能力は〜で効果を発揮する」 | 第5弾以降の書式。書かれた場所（戦場・魔力ゾーン・墓地）にある間だけ、条件を満たせば効果を持つ常在能力。「発動する／発動できる」と書かれた能力ではない |

## 11. カードデータ（cards.json）について

- **全576種**（スターター5種、第1〜6弾ブースター）。名前・色・レベル・パワー/コスト・特性・遺業・効果文・カード画像URL（公式）を収録。
- `textStatus: "verified"` … 公式Q&A・Wikiのカードページと突き合わせ済み（**スターター赤・青・緑の39種**）。公式Q&Aの要点を `notes` に入れている。
- `textStatus: "sourced"` … 非公認のデッキ作成アプリ「イジンデッキ」（すいーとポテト氏、MITライセンス）のカードデータ由来。上の39種と第1〜3弾の数値はWikiと全件一致したので、信頼性は高い。
- 効果文の改行は `\n`。1行がキーワードだけの行（例:「即応」「ダブルプレッシャー」）は `keywords` にも入れている。
- 第5弾・第6弾のIDは公式表記に合わせて `2nd1-` / `2nd2-` で始まる。
- `anyNumCopies: true` はデッキに何枚でも入れてよいカード（各色ストーン）。
- 【実装方針】効果の実装はカードごとの手書きが必要。初期リリースはスターター3デッキ（39種）だけを有効にし、ほかのカードは順に対応する。

### 実装に関わる注意（スターター3種）
- 効果の対象選択（「1体を指定して」など）は、能力の持ち主がUIで選ぶ。
- 「アタッカーになったとき」は、アタックステップで全アタッカーを指定し終えた後に、ターンプレイヤーが好きな順で処理する。
- 「連なる天守閣」は使用時のレベルが1になる（自分の戦場に剣術イジンがいれば）。
- 「好太王」は防御で使えない。
- 「武帝」のパワーは常に再計算（自分の戦場のイジン数×1000 を加算）。
